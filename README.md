# Lesezeit

A private, phone-first PWA for reading German news at B1–C2 and training vocabulary from it. Built for a single user; the reading content and personal progress live in a separate private repository.

- App: https://enesskocc.github.io/lesezeit/
- Spec: [SPEC.md](SPEC.md) · Progress: [PROGRESS.md](PROGRESS.md)

Stack: Vite, React, TypeScript, Tailwind, vite-plugin-pwa, Dexie (IndexedDB), Zod.

```
npm ci
npm run dev
```
